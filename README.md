This repository contains the code to create surface wind forcing that accounts for wind farm wakes used in the [DTO4OWE](https://dto4owe.eu/) project. 

Here we use polygons from [DTO4OWE_polygons](https://github.com/AleksiNummelin/DTO4OWE_polygons) repository and compute the wakes using DestinE data downloaded with code from [DTO4OWE_ExtractForcing](https://github.com/AleksiNummelin/DTO4OWE_ExtractForcing) .

With small modifications (mainly to file names and regridding), it is possible to compute wakes using other products as well.
